# Task Priority Manager

A Java console application for managing tasks, priorities, and completion status.

## Overview

Task Priority Manager is a simple command-line application that allows users to create and manage tasks.

Users can:

- Add new tasks
- Assign priorities
- View existing tasks
- Mark tasks as completed
- Remove tasks
- Exit the application

The project demonstrates fundamental Java programming and object-oriented programming concepts.

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
